# FreeTrust

**Freedom to trust: identity you own, proven only as far as you choose, and
trusted through people you know.**

FreeTrust is the umbrella vision behind several rhovision-org projects. It
started around 2016 as voluntary web-of-trust identity on the Synereo
platform, with blockchain provenance, integration with the national identity
ecosystem, and user managed authorization (UMA). The goals still hold. The
technology has moved on, so this repo maps each FreeTrust capability to the
project that now builds it.

This repo holds no code. It holds:

- [CAPABILITIES.md](CAPABILITIES.md): each FreeTrust capability, the modern
  approach, the repo that owns it, and the issues that track it.
- [COOPERATIVE.md](COOPERATIVE.md): a proposed platform cooperative that
  owns and governs FreeTrust, starting with a BYOID community in rhogov.
- [DECISIONS.md](DECISIONS.md): where each repo records its decisions, plus
  the choices that apply across repos.

## The projects

| Repo | Role in FreeTrust |
| --- | --- |
| [BYOID](https://github.com/rhovision-org/BYOID) | Self-sovereign identity: DIDs on rholo, credentials, selective disclosure, recovery. See its [roadmap](https://github.com/rhovision-org/BYOID/blob/main/ROADMAP.md) and [contract plan](https://github.com/rhovision-org/BYOID/blob/main/docs/contracts.md) |
| [rholo](https://github.com/rhovision-org/rholo) | The trust less Rholang blockchain that DIDs, contracts and native computations run on |
| [quantum-os](https://github.com/rhovision-org/quantum-os) | Peer-to-peer rooms with capability tokens, group decisions and governance |
| [rhogov](https://github.com/rhovision-org/rhogov) | Governance on rholo: groups, liquid democracy, web of trust, censure |
| [quantum-logical-framework](https://github.com/rhovision-org/quantum-logical-framework) | The formal foundation, verified in Lean, including the maximum relative entropy work |
